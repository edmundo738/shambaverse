# Shambaverse

Plataforma agrotech completa com frontends React (mobile/web), API Node.js/Express, serviço ML em Python, Firebase para tempo real e PostgreSQL.

## Estrutura

- `frontend/` apps mobile (React Native) e web (React PWA)
- `backend/` API Node.js/Express
- `ml-service/` serviço de ML em Python/Flask
- `firebase/` regras e funções
- `database/` schema e seeds
- `docker/` arquivos de containerização
- `docs/` documentação
